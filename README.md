# Movie Rating Prediction Using Python

## Project Description
This project uses Machine Learning to predict movie ratings based on movie details.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
Random Forest Regressor

## Dataset
IMDb Movies India dataset from Kaggle.

## Output
- Displays the cleaned movie dataset.
- Trains a machine learning model to predict movie ratings.
- Displays the Mean Absolute Error (MAE) to evaluate prediction accuracy.
- Generates a graph comparing actual ratings with predicted ratings.
- Predicts a rating for a sample movie.

## Conclusion
This project demonstrates data cleaning, machine learning model training, movie rating prediction, and model evaluation using Python.
